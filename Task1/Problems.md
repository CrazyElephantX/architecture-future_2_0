# Текущие проблемы

1. Монолитный DWH с «зашитой» бизнес-логикой: тормозит изменения и вывод новых продуктов 
2. Устаревшие SQL Server 2008/PowerBuilder: высокий риск отказоустойчивости и дефицит навыков на рынке 
3. Тяжёлые трансформации и отчёты часами: задержки управленческих решений и просрочки регуляторной отчётности 
4. Единая кастомная BI поверх DWH: низкая скорость самообслуживания доменов 
5. Шина Apache Camel как узкое горлышко: задержки интеграций, дубли логики, ошибки, потенциальная проблема с производительностью 
6. Нет чётких доменов: дубли клиентов/счетов/персонала -> неверные KPI и финансовые ошибки 
7. Проблемы с конфиденциальностью PHI/PII: риски несоответствия мед. требованиям -> штрафы и блокировки 
8. Отсутствие метрик: риск длительного анализа пробелм

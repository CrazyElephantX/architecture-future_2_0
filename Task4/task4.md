## 2. Файлы конфигурации Terraform
- **main.tf** — описание инфраструктуры (VPC, подсети, ВМ, диски, NAT).
- **variables.tf** — определение переменных (размеры ВМ, количество инстансов, CIDR).
- **outputs.tf** — вывод ключевых параметров (IP‑адреса, инвентарь).
- **terraform.tfvars** — значения переменных для окружения dev.
